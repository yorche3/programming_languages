## 1. Alcance / Scope

2. Revisión del andamiaje de **los 50 lenguajes**: toda adecuación conocida que sea

   escondida como tarea habitual del delegado `scaffold`.

**EN:** Two deliverables serving existing sprint steps: explicit delegate routes,
per-request models and constrained overrides; and a 50-language scaffold review
that moves known repeatable adaptations into the catalogue and manual guide.
OpenRouter uses Copilot CLI with BYOK, not a new agent.

**ES:** Fuera de alcance: implementación de módulos, cierre del roadmap académico,
instalación de toolchains, gestión de credenciales, nuevos verbos de auditoría y

opiniones manuales, sin convertir los audits en encargos ejecutables de glot.

**EN:** Module implementation, academic roadmap closure, toolchain installation,

## 3. Rutas y selección / Routes and selection

| `--delegate` | Herramienta / Tool | Ruta / Route |
|---|---|---|
| `antigravity` | `agy` | Catálogo y cuota de Antigravity |
| `copilot` | `copilot` | Modelos nativos de GitHub Copilot |
| `open-router` | `copilot` | Endpoint OpenRouter mediante BYOK |

**ES:** No se añade `--provider`. Se conservan `agy`/`cop` como alias existentes;
la ayuda y el completado ofrecen los tres nombres canónicos. `--model <alias|id>`
es un override dentro de la ruta y del conjunto de pasos autorizados, nunca una
forma implícita de cambiar de proveedor.

**EN:** No `--provider` option is added. Existing `agy`/`cop` aliases remain;
help and completion expose the three canonical names. `--model <alias|id>`
overrides within the selected route and allowed request set, never implicitly
switching providers.

**ES:** Reglas de resolución:

- Resolver **ruta → encargo/perfil → modelo → parámetros compatibles**.
- La opción explícita gana a la selección persistente. Sin selección explícita,
  conservar la elección no ambigua del delegado configurado; si hay varias rutas
  elegibles, devolver `2`, como hoy, sin pedir datos interactivamente.
- Modelo explícito por flag, después variable aplicable a la ruta, después alias
  persistente y finalmente modelo del encargo. **Todos** pasan la misma validación.
- Una configuración BYOK disponible no cuenta como una ruta nativa independiente
  automáticamente: el catálogo declara las rutas elegibles, no solo los binarios.
- No cambiar ruta/modelo por cuota agotada, error, parámetro incompatible o falta
  de disponibilidad. Informar la causa y dejar la elección al autor.
- Distinguir dato incompleto (`1`), override inválido (`2`) y estado ilegible (`3`);
  no anunciar una ejecución correcta si el delegado falló.

**EN:** Resolve route before request/profile, model and compatible parameters.
Explicit selection wins; ambiguous routes retain exit `2`. Every model source
uses the same authorization checks. Route availability is not inferred merely
from installed binaries. No automatic model/provider fallback; preserve existing
exit-code distinctions and report delegate failures.

### Datos y migración / Data and migration

**ES:** Mantener el formato TSV y reutilizar los catálogos existentes. La
implementación debe separar la **política del perfil** de la identidad del modelo:
el modelo no puede seguir siendo la clave única que decide presupuesto y encargo.
Las plantillas declararán su perfil; el catálogo declarará la asociación
`ruta + perfil/encargo + modelo predeterminado` y los overrides autorizados.
El esquema exacto se fijará junto con el lector y sus pruebas, sin duplicar el
estado de modelos en YAML ni añadir un gestor genérico de proveedores.

**EN:** Retain TSV and reuse existing catalogues. Separate profile policy from
model identity: model ID must no longer uniquely determine request and budget.
Templates declare profiles; catalogues declare route/request defaults and allowed
overrides. Final column schemas ship with readers and tests, without duplicate
YAML configuration or a generic provider-management layer.

**ES:** Mantener las órdenes personalizadas del autor y las claves conocidas de
AGY. Separar el estado de alias nativo y OpenRouter; la migración de
`copilot-model` debe distinguir los alias BYOK existentes y anunciarlos como tales.
No reinterpretar un id arbitrario como nativo ni migrar una selección ambigua sin
avisar. `finish` conserva selecciones de ruta/modelo, no el estado de un sprint
cerrado. La instalación debe copiar y comprobar la deriva de los nuevos datos.

**EN:** Preserve author-owned custom commands and known AGY settings. Separate
native and OpenRouter alias state; explicitly identify legacy BYOK aliases during
migration. Never guess ambiguous IDs. `finish` preserves route/model preferences,
not completed sprint state; installation and drift checks cover changed data.

## 4. Configuración BYOK y equivalencias / BYOK configuration and equivalence

**ES:** Se consultó **solo la ayuda local** `copilot help providers` y
`copilot help config`, sin autenticación, inferencia ni lectura de claves.
La documentación oficial actual también describe `providers.json`; esa
configuración del usuario y la configuración BYOK de VS Code no son los TSV de
glot ni son intercambiables con ellos.

**EN:** Only local CLI help was queried, without authentication, inference or
credential inspection. Official documentation also describes user-owned
`providers.json`; neither it nor VS Code BYOK settings are glot TSV configuration.

| Aspecto / Aspect | Copilot CLI BYOK | Política v2.1.0 / Policy |
|---|---|---|
| Endpoint y tipo / Endpoint and type | `COPILOT_PROVIDER_BASE_URL`, `COPILOT_PROVIDER_TYPE` | OpenRouter: `https://openrouter.ai/api/v1`, tipo `openai`; no deducirlo de `/` |
| API y transporte / API and transport | `COPILOT_PROVIDER_WIRE_API`, `COPILOT_PROVIDER_TRANSPORT` | `completions` + `http` como base OpenRouter; otra combinación exige compatibilidad comprobada |
| Identidad / Identity | `COPILOT_MODEL`, `COPILOT_PROVIDER_MODEL_ID`, `COPILOT_PROVIDER_WIRE_MODEL` | Distinguir id del agente de id enviado; no inventar una familia conocida para un modelo distinto |
| Entrada / Input | `COPILOT_PROVIDER_MAX_PROMPT_TOKENS` | Entero positivo dentro de la capacidad real; reservar espacio para salida y razonamiento cuando compartan ventana |
| Salida / Output | `COPILOT_PROVIDER_MAX_OUTPUT_TOKENS` | Entero positivo dentro del límite real; no copiarlo entre modelos |
| Esfuerzo / Effort | `--reasoning-effort` | Validar nivel por modelo/ruta y documentar la traducción, si existe |
| Cabeceras / Headers | `COPILOT_PROVIDER_HEADERS` | Configuración externa; puede contener secretos, no imprimirla ni versionarla |
| Credenciales / Credentials | `COPILOT_PROVIDER_API_KEY`, `COPILOT_PROVIDER_BEARER_TOKEN`, `COPILOT_PROVIDER_API_KEY_COMMAND` | Del autor; no leer valores, ejecutar su comando para comprobarlos, guardar ni mostrar secretos |
| Archivo del usuario / User file | `providers.json`, `COPILOT_PROVIDERS_CONFIG` | No crear, editar ni copiar ese archivo desde glot |

**ES:** `COPILOT_MODEL` puede cubrir identidad y wire model cuando coinciden.
Cuando no coinciden, la asociación debe ser real y comprobable; un modelo
desconocido no se hace equivalente a GPT o Claude cambiando `MODEL_ID`.
Los valores de tokens no amplían el contexto real. Tool calling y streaming
son requisitos del delegado agéntico; el contexto útil puede ser menor que el
anunciado por el proveedor debido a límites del CLI y al historial.

**EN:** `COPILOT_MODEL` can cover both identities when they match. A differing
agent identity must be genuinely compatible, not a fabricated GPT/Claude alias.
Token settings do not enlarge real context. Agent delegation requires tool
calling and streaming; usable context may be below advertised provider limits.

### Parámetros de perfil / Profile parameters

- **ES:** `economy`: esfuerzo lógico `low`; `balanced`: `low`; `deep`: `medium`.
  Los overrides heredan esa intención, no ciegamente los flags del modelo anterior.
  Un esfuerzo explícito incompatible bloquea con `2`; una asociación sin
  traducción comprobada bloquea con `1`.
  **EN:** Logical efforts are low/low/medium. Overrides inherit intent, not
  incompatible flags. Reject explicit unsupported settings with `2` and missing
  verified adapter data with `1`.
- **ES:** AGY actualmente expresa el esfuerzo en ids como
  `gemini-3.8-flash-low` y `claude-sonnet-5-5-low`. Verificar cómo el CLI instalado
  representa `medium` y Argon; no anunciar `medium` si se envía un id `low`.
  **EN:** Verify AGY's effort encoding before claiming medium effort or enabling
  Argon; an ID ending in low does not demonstrate medium execution.
- **ES:** Los topes nativos de Copilot pueden conservar `30/60/90` por perfil
  donde el CLI los soporte. Son caps blandos de AI credits, **no** límites de
  dinero OpenRouter ni cuotas de Antigravity. No enviar ese cap como garantía
  BYOK; el autor controla gasto/límites en el proveedor.
  **EN:** Retain native Copilot credit caps where supported, but never interpret
  them as OpenRouter monetary limits or Antigravity quotas.
- **ES:** No añadir `temperature`, `top_p`, token budgets de razonamiento u otros
  parámetros solo porque la API del proveedor los ofrezca: glot solo documenta
  y transmite controles que la herramienta instalada soporte y que se hayan
  comprobado. No es necesario fijarlos todos para usar BYOK.
  **EN:** Do not add API knobs unless the actual installed tool supports them
  and their transport is verified; BYOK does not require every possible parameter.

### Aislamiento / Isolation

**ES:** Cada ejecución recibe su configuración en un entorno hijo. La ruta
`copilot` no puede heredar endpoint, wire model, límites, archivo de proveedores o
cabeceras BYOK que la desvíen de GitHub; AGY no recibe configuración de Copilot.
`open-router` no puede apuntar silenciosamente a otro endpoint por una variable
heredada: detectar el conflicto y reportarlo. No alterar el entorno del shell
del autor. Mostrar ruta, perfil, modelo, esfuerzo efectivo y límites no sensibles;
jamás claves, cabeceras ni la expansión de un comando de credenciales.

**EN:** Scope configuration to child executions. Native Copilot must not inherit
BYOK routing/model/token overrides; AGY must not receive Copilot settings.
Report conflicting OpenRouter endpoints instead of silently rerouting. Do not
mutate the author's shell. Diagnostics expose only non-sensitive effective settings.

**ES:** `ask`, `validate`, `models`, `delegates`, ayuda, completado, `doctor`,
instalación y `-n` deben describir la misma política. `validate` conserva su
contrato de solo lectura y evidencia; no obtiene una segunda resolución
independiente. La compatibilidad de un `GLOT_VALIDATOR` personalizado se comprueba
sin inyectar flags arbitrarios en su orden.

**EN:** All model-selection surfaces share policy, including `validate`, which
retains its read-only evidence contract. Custom validators must not receive
arbitrary injected flags.

### Ballerina: decisión concreta / Concrete decision

**ES:** La fila actual solo elimina un `.git` anidado y toca `.gitignore`; su
nota «revisar tests/ generado» no crea ese directorio. Las bases muestran
`{module}.bal` en la raíz y pruebas en `tests/`. Se acuerda:

1. Conservar `bal new {module}` en la fase `new`.
2. Crear `tests/` si falta y `tests/lib_test.bal` **vacío** si falta.
3. Renombrar `main.bal` a `{module}.bal` cuando exista el archivo generado y no
   exista el destino; Ballerina conserva el id canónico con subrayados.
4. Verificar que el resultado sea biblioteca: renombrar no elimina una función
   `main`. Eliminar/adaptar contenido de ejemplo solo con una transformación
   comprobada; contenido desconocido se reporta, no se borra.
5. Mantener `.gitignore` sin truncar y no escribir casos unitarios. El nombre
   `lib_test.bal` sigue la base prioritaria; no obliga a que toda suite futura
   viva en ese archivo.

**EN:** Keep `bal new`; create missing `tests/` and empty `tests/lib_test.bal`;
rename a known generated `main.bal` to canonical `{module}.bal` without replacing
an existing target. Renaming does not remove a main function: verify library
semantics separately. Preserve ignore contents and leave test cases to `suite`.

**ES:** Receta manual **objetivo**, aún pendiente de ejecución nativa en laboratorio.
Se ejecuta desde la raíz del paquete, con los nombres resueltos:

```bash
mkdir -p tests
test -e tests/lib_test.bal || touch tests/lib_test.bal
# Solo después de comprobar origen generado y destino ausente:
mv main.bal {module}.bal
```

**EN:** Target manual recipe, not yet native-tested. The rename is conditional
on a verified generated source and absent destination; this block is not an
unconditional rerunnable scaffold implementation.
