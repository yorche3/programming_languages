# Fundamentos / Foundations

Esta sección reúne los conceptos esenciales que necesitas para empezar a trabajar con diferentes lenguajes de programación e implementar la forma más atómica de probar tu código (pruebas unitarias). A partir de estas bases, podrás construir proyectos cada vez más avanzados, teniendo un ejemplo práctico y estructurado para seguir en tus desarrollos.
