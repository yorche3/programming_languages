# Roadmap Update Checklist / Registro de cierre

Este archivo registra los cierres que autorizan una actualización de
`docs/ROADMAP.md`. Es parte del flujo de documentación: una delegación no está
finalizada hasta que el registro y el roadmap reflejan el mismo estado.

## Regla de cierre / Completion rule

Para cerrar un módulo, comprobar código, tests y README. Para cerrar una fase,
comprobar además todos sus módulos requeridos. Solo después se cambia el estado
en `ROADMAP.md`.

Cada entrada debe incluir la fecha, la fase, el módulo o conjunto de módulos,
los lenguajes verificados, los comandos ejecutados y el cambio de estado
realizado en el roadmap. No se deben inventar resultados.

La primera versión de la implementación usaba la convención de lista (`my @array = @_;` y `return @array;`), mientras que la suite pasa un arrayref, lo que hacía fallar las 24 comprobaciones con `GOT: 1` frente a `CHECK: <ARRAY>`: con un solo argumento, `@array` es una lista de un elemento y `$n` vale 1, así que ningún caso ordenaba nada. El autor autorizó reescribirla con la API por arrayref, que es además la única forma de que el ordenamiento sea realmente in-place sobre los datos del llamador, porque un `sub` de Perl recibe siempre una lista de argumentos. El caso nulo se incluye, a diferencia de Nim y OCaml: Perl tiene `undef` como valor de «ausencia de valor», así que `return undef unless defined $arr;` es el indicador de fallo idiomático y `defined $arr` distingue `[]` de `undef`, dando 8 casos (los 7 de la especificación más el nulo). Los tres algoritmos ordenan in-place el arrayref recibido y devuelven ese mismo arrayref, y los tests aíslan cada caso con `[@$input]` sobre los fixtures compartidos. La comparación usa `is_deeply` porque `is` compararía las direcciones de los arrayrefs y no sus contenidos. El helper recibe la función como referencia (`\&selection_sort`) y ejecuta los 8 casos con el mensaje del contrato como nombre de la aserción, de modo que un fallo aparece como `not ok 1 - selection_sort should sort an unsorted array`. La bandera `swapped` se implementa con `last unless $swapped;`, que es el `break` de Perl y equivale literalmente al `if not swapped then break` del pseudocódigo. Las cotas reproducen las del pseudocódigo porque el rango `..` de Perl es inclusivo en ambos extremos y devuelve lista vacía cuando la cota superior es menor que la inferior, así que no hacen falta guardas para arrays de 0 o 1 elementos. `insertion_sort` desplaza con `$arr->[$j] > $key` estricto, lo que la hace estable. Las funciones usan `snake_case` (`selection_sort`), que coincide con el nombre de la especificación, y son `sub` globales del paquete `main` a los que la suite llega por nombre tras el `require`.
